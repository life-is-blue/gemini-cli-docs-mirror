### `/ide`

- **Description:** Manage IDE integration.
- **Sub-commands:**
  - **`disable`**:
    - **Description:** Disable IDE integration.
  - **`enable`**:
    - **Description:** Enable IDE integration.
  - **`install`**:
    - **Description:** Install required IDE companion.
  - **`status`**:
    - **Description:** Check status of IDE integration.
